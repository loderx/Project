# PhotoCalendar (LOD Corporation v2.4)

PHP/MySQL/AJAX система за фото студиа с multi-tenant архитектура.

## Функции
- Инсталатор (`installer.php`) за първоначална настройка.
- Login, роли (`admin` / `user`) и автоматична деактивация след `active_until`.
- Собствен календар за всеки фотограф + събития с дата, начален/краен час (24h), локация, тип, цена и клиент.
- Клиенти, категории услуги, приходи/разходи, dashboard с графика (Chart.js).
- Оферти към клиенти, изпращане по email и изтегляне като PDF.
- Админ панел за потребители и upload на лого (показва се и на login).
- Тъмна/светла тема чрез AJAX.

## Стартиране
1. Създай виртуален хост или стартирай:
   ```bash
   php -S 0.0.0.0:8080
   ```
2. Отвори `http://localhost:8080/public/index.php` и системата ще те пренасочи към `installer.php`.
3. Въведи MySQL данни и админ акаунт.

## Структура
- `public/index.php` - основен front controller + модули.
- `schema.sql` - база данни.
- `src/bootstrap.php` - auth/db helper-и.
- `src/pdf.php` - базов PDF генератор за оферти.
