# Modern Modular PHP System

Това е модерен PHP/MySQL скелет за модулна система с админ панел, абонаменти и светъл/тъмен режим.

## Структура
- `public_html/` — основната директория, която се качва в хостинг.
- `public_html/modules/` — папки за модули (всеки модул има `manifest.json` и по желание `migrate.php`).

## Инсталация
1. Качи съдържанието на `public_html/` в главната директория на хостинга (например `public_html`).
2. Отвори `install.php` през браузър и попълни данните за MySQL.
3. След инсталацията логинът е на `index.php?page=login`.

## Модулна система
- Постави нов модул в `public_html/modules/<module>`.
- Активирай/деактивирай модула от **Админ → Модули**.
- Ако модулът има `migrate.php`, той се изпълнява при активация за да добави нужните таблици.

## Архив (ZIP)
За да подготвиш архив за качване:
```bash
zip -r modern_system.zip public_html
```
